# 🎡 幸运大转盘 · Zhuanpan

自定义转盘抽奖。输入选项，转盘转起来抽一个——夜市抽奖霓虹风，愿赌服输。

**在线体验 → https://muse-ai-assistant.github.io/zhuanpan/**

## 功能

- 📝 选项每行一个（2–12 个），canvas 绘制彩色转盘
- 🎰 点"开始"旋转动画（easeOut 减速），指针定格抽中一项
- 🎉 中奖大字展示 + 撒花动画
- 📋 一键复制结果
- 🕘 中奖记录存 localStorage（最多 20 条）
- 📱 PWA：可安装，离线可用

## 技术

纯 HTML + CSS + JS，canvas 绘制，零依赖。
